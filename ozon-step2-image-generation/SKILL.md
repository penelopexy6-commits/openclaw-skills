# OZON 电商主图生成流程（Step 2）

## 概述

将货盘原图处理为 Ozon 电商主图，分两步：去文字抠白底 → 按8图框架批量生成。

**数据来源：** Step 1 采集的 Excel 文件（竞品总表 + 关键词总表 + 主题标签总表）

**数据获取优先级：** `Step1 Excel 优先 → 没有再爬竞品详情页补充`
- Step1 已有（品名/关键词/售价/图片参考）→ 直接用
- Step1 没有的规格参数（功率/尺寸/颜色等）→ 去 Ozon 竞品详情页扒

## 步骤 2.1 — 原图去文字 + 抠白底

**用途：** 将货盘原图（带文字标签）处理为干净的白底产品图，作为 Step 2.2 的素材源。

**接口：** `POST /openapi/v1/banana_pro/image-to-image`

**请求体：**
```json
{
  "imageUrls": ["<原图COS_URL>"],
  "prompt": "去除原图中的非产品标识文字标签，保留产品品牌logo和标识。将背景替换为干净的纯白色。产品保持原造型、原配色、原材质细节不变。优化光影均匀度，减少阴影。整体效果为干净的白底产品图，适合作为电商主图素材。",
  "aspectRatio": "3:4",
  "resolution": "1k"
}
```

**价格：** 13积分 = 0.13元/张

**流程：**
1. 原图上传 COS 获取公开 URL
2. 调 Banana Pro API 提交图生图任务
3. 轮询 `POST /openapi/v1/query`（每5秒，最多60次）直到 status=SUCCESS
4. 下载临时图 → 上传 COS 永久存储
5. 白底图 URL → 传给 Step 2.2

## 步骤 2.2 — 8张主图批量生成

**用途：** 基于白底图和 8 图框架，按品类自动生成全套 Ozon 主图。
**框架文件：** `scripts/ozon_framework.py`

### 8张图结构

| # | 文件名 | 角色 | 文案来源 |
|---|---|---|---|
| 01 | `_01_main.png` | **封面主图** 中心构图，1主标题+3-5卖点卡+底部+角标 | 品名+高曝光关键词 |
| 02 | `_02_trust.png` | **功能强化** 信任背书，打透核心卖点 | 高增长关键词Top5 |
| 03 | `_03_scene.png` | **场景代入** 平放贴合，25-35%场景背景 | 品名（使用场景） |
| 04 | `_04_scenes.png` | **场景拓展** 2×2网格多场景 | 主题标签 |
| 05 | `_05_detail.png` | **细节拆解** 核心部件高亮放大 | 卖点词/规格参数 |
| 06 | `_06_maintenance.png` | **保养展示** 维护说明 | 通用模板 |
| 07 | `_07_comparison.png` | **差异对比** 对比分区，突出优势 | 竞品数据参考+卖点词 |
| 08 | `_08_audience.png` | **人群覆盖** 4个人群卡片 | 主题标签+品类词 |

### 全局规则（所有8张通用）

1. **产品锚定：** 以白底图为唯一产品锚点，原造型/配色/材质/结构不变
2. **文字规范：** 横向正向阅读，不压产品核心区，禁止臆造logo、乱码
3. **强调色：** 全图仅1种，仅用于核心数字/标签/关键图标
4. **视觉证据：** 正向体现价值，清洁类新品禁止灰尘/脏污
5. **背景：** 禁纯白死白，浅质感/弱场景，场景占比≤15%
6. **布局：** 产品略微放大，顶部标题别太高，底部文字别贴底

### 主图专属规则（仅01适用）

- 中心稳定构图，产品占比45%-60%
- 斜前侧视角，展示正面操作区与核心功能
- 1主标题+3-5张统一卖点卡+1底部补充+1角标
- 严格3级信息分层

**价格：** 8张 × 13积分 = 104积分 = 1.04元/SKU

### 并发策略

Banana Pro API 支持并发，8 张图不用串行等待。

```
1. 同时提交 8 个图生图任务（task1 ~ task8）
   请求间隔 10ms，几乎同时发出

2. 轮询阶段
   同时查 8 个 task 的状态
   无需等一个完成再提交下一个

效果：8张图从 ~6分钟 缩到 ~40秒
```

## 使用方式

```bash
# 完整流程：去文字抠白底 → 8张图 → COS
python scripts/step2_generate.py \
    --sku I88 \
    --source-url <货盘原图URL> \
    --prompts I88

# 跳过抠白底，直接用已有白底图
python scripts/step2_generate.py \
    --sku I88 \
    --source-url <原图URL> \
    --prompts I88 \
    --skip-whitebg \
    --whitebg-url <已有白底图COS_URL>
```

## 注意事项

1. `imageUrls` 最多传 10 张，每张不超过 10MB
2. 临时图 URL 10分钟有效，需及时下载转存 COS
3. 不同品类的 8 图 prompt 需差异化
4. 价格低于 3000₽ 的品偏向实用/性价比图风，5000₽ 以上偏向高端/精致
5. 8张图的 prompt 模板推荐一次性提交 8 个任务并行，省时间
6. 没配 `banana-config.json`？直接从 TOOLS.md 抄 API Key 进去
